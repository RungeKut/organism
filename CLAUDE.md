# organism

Саморасширяющийся ИИ-организм на Python 3.10 (stdlib, без зависимостей): ствол, граф акторов, потоки-органы, сон. Стадия: скелет работает на FakeLLM.

## Инварианты

- Уровень 0 (`stem.py`, `config/territory.json`) не переписывается организмом и не наследуется.
- Действовать в мир может только выход (`organism.py`: голос, рука); потоки лишь предлагают.
- Потоки — органы одного «я», не отдельные агенты.
- Веса графа меняются только во сне.
- Вне территории (сеть, чужие машины) — только по списку человека.

## Карта

- `docs/50_status/STATE.md` — читать первым
- `docs/INDEX.md` — какой файл когда
- `docs/00_rules/` — процесс

## Процесс

1. Шаг = коммит + STATE.md; контекст ~100–200К.
2. Документ ≤ 6 КБ, ссылки вместо копий.
3. Комментарии в коде запрещены по умолчанию.
4. Бриф агенту — по `docs/00_rules/agents.md`; ответ ≤ 15 строк.
5. Push и необратимое — только по команде человека.
6. Исполнители не правят этот файл и STATE.md.

## Проверка

- test: `uv run --python 3.10 python -m unittest discover -s tests -t .`
- demo: `uv run --python 3.10 python -m organism --demo`
