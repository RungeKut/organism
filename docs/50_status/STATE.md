## Протокол с сервером

- Доступ: агент не входит на сервер и не вводит пароли; команды выполняет человек (план — `docs/40_hardware_plan.md`).
- Когда нужна проверка на железе, агент создаёт `go.md` в корне проекта (в git не попадает). Человек выполняет шаги, кладёт результаты в `result/` и переносит `go.md` в `result/`; исчезновение `go.md` из корня = «готово».
- Готово к запуску на сервере: `scripts/hw_probe.py` (зонд железа), `scripts/hw_llama.py` (сборка и замеры llama.cpp, по умолчанию только печатает план).
