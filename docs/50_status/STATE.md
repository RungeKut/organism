# Состояние (точка возобновления)

Обновлено: 2026-10-26

## Цель

Скелет самоорганизующегося организма по разделам 20–24 конспекта: ствол, граф акторов, потоки-органы, сон, мать-заглушка.

## Сделано

- Уровень 0: фазы и такт, лимиты, территория, рефлексы исполнителя (`stem.py`, `executor.py`).
- Граф с следами пригодности и консолидацией только во сне (`graph.py`).
- Потоки по умолчанию: речь, моторика, тело; сцена и селектор; единый выход (`streams.py`, `workspace.py`, `organism.py`).
- Сон: переигрывание эпизодов, оценка матерью, заметка памяти, метаболизм потоков, деление (`sleep.py`, `mother.py`).
- Карта тела, AIMD для слотов LLM (`body.py`, `llm.py`); CLI `python -m organism`.

## Проверено

- 29 тестов проходят на Python 3.10 (uv), машина: 6 ядер, 8 ГБ, Windows.
- `--demo` на FakeLLM: бодрствование → сон (вход блокируется) → бодрствование; веса речь→моторика выросли, заметка записана.
- Не проверено: реальный llama.cpp, EPYC, NUMA, LoRA, нагрузка, поведение за часы.
