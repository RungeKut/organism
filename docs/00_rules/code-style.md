# Код

- Комментарии в коде запрещены по умолчанию: допустим только комментарий,
  объясняющий неочевидное «почему» (ошибка в документации, ограничение
  железа) со ссылкой на `docs/`.
- Python 3.10, только stdlib в ядре; `psutil` — необязательная зависимость (`body`).
- Идентификаторы английские, строки, промпты и имена событий русские.
- Всё, что меняет мир, идёт через `Executor`; в обход выхода не действовать.
- Лимиты и территорию не мягчить в коде: они лежат в `config/territory.json`.
- Проверка перед каждым коммитом:
  `uv run --python 3.10 python -m unittest discover -s tests -t .`
