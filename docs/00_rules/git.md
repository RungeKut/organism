# Git

- Один шаг — один коммит; push — только по разрешению человека (или заранее
  оговорённому правилу проекта).
- `.gitignore` создаётся **до** первого `git add -A`: артефакты сборки
  (`build/`, `target/`, `node_modules/`, `__pycache__/`) в историю не попадают.
- Автор коммитов — из `git config` репозитория; не менять `--global`.
- Сабмодули: после клона `git submodule update --init`; обновление ссылки —
  отдельный коммит. Вложенные `AGENTS.md`/`CLAUDE.md` сабмодулей суммируются
  с корневым при старте субагента — держать их короткими.
- Публичная копия репозитория: адреса внутренних серверов в документы не
  писать.
