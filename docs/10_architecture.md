## Поток событий

1. `Organism.say` → событие `вход` → Speech (маршрут через `Graph.route`).
2. Speech думает через LLM, получает конверт (`protocol.py`); адресат «моторика» → `Stream.forward` → Motor, адресат «пользователь» → предложение «голос».
3. Motor кладёт предложение «рука». Селектор (`Workspace.select`) на каждом такте берёт лучшее предложение на орган; проигравшие ждут до срока.
4. Выход исполняет: голос отвечает, рука идёт через `Executor` (allowlist, лимит в час, таймаут, без shell) и шлёт `результат` обратно.
5. Срок считается от начала обработки запроса потоком (`Stream.started`); просрочка = боль: награда −0.3, тело замедляет такт.

## Фазы

`Stem.tick`: бодрствование → засыпание (ждёт `busy()==0` или `drowsy_max_s`) → сон → бодрствование. Вход в сон не принимается. Давление сна: `wake_s` или `sleep_pressure_events`.

## Сон (`sleep.py`)

1. Переигрывание журнала по эпизодам; мать (`mother.py`) оценивает эпизод, награда × `Mother.share()` падает с возрастом.
2. `Graph.consolidate`: `dw = eta*credit − decay*w`, шаг ≤ `max_dw`, входящие веса нормируются, неиспользованные нулевые связи срезаются.
3. Заметка памяти (сжатие дня) → `journal.memory`, подмешивается в промпт Speech.
4. Метаболизм: `earned − spent < 0` два сна подряд → смерть непервичного потока; очередь ≥ 3 → деление `речь-2`.

## Рост и ограничения

- Новый поток: `Organism.spawn` → `Stem.request_stream` (лимит потоков, запас ядер `headroom`).
- Первичные потоки (`речь`, `моторика`, `тело`) не умирают.
- LLM-слоты: `AIMD` — +1 после серии успехов, ÷2 при сбое, потолок `max_llm_slots`.
- Карта тела: `body.py` (ядра, ОЗУ, NUMA-узлы без памяти) → `state/bodymap.json`.
